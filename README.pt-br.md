<h1>Sorteador de Números - Grunt</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Uma aplicação web de sorteio de números desenvolvida em <strong>JavaScript</strong>
    e estilizada com <strong>LESS</strong>. O projeto utiliza o <strong>Grunt</strong>
    como task runner para automatizar tarefas de desenvolvimento e produção.
</p>
<p>
    🔗 Live Demo: <a href="https://sorteadorgrunteduardo-three.vercel.app" target="_blank">Ver na Vercel</a>
</p>
<h2>Sobre</h2>
<p>
    O projeto foi criado para explorar e praticar a automação de tarefas com o Grunt.
    Inclui a configuração de múltiplos plugins para otimizar fluxos de trabalho tanto
    em desenvolvimento quanto em produção. O usuário pode inserir um número máximo,
    e a aplicação gera um número aleatório dentro do intervalo definido.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>JavaScript</li>
    <li>LESS</li>
    <li>Grunt</li>
    <li>HTML5</li>
</ul>
<h2>Funcionalidades</h2>
<ul>
    <li>Compilação de LESS para CSS;</li>
    <li>Minificação de HTML, CSS e JavaScript;</li>
    <li>Substituição dinâmica de caminhos de arquivos para builds;</li>
    <li>Limpeza de pastas temporárias de build;</li>
    <li>Monitoramento de arquivos e reconstrução automática;</li>
    <li>Execução concorrente de tarefas para maior velocidade.</li>
</ul>
<h2>Destaques dos Commits</h2>
<ul>
    <li>Configuração do Grunt com tarefas para desenvolvimento e produção;</li>
    <li>Adicionada compilação de LESS e minificação de CSS;</li>
    <li>Implementada minificação de HTML e JavaScript para builds otimizados;</li>
    <li>Configurado Grunt Replace para manipulação dinâmica de caminhos de arquivos;</li>
    <li>Melhorada a validação do formulário e o comportamento do input de número;</li>
    <li>Estilizadas mensagens de resultado e ajustado o layout responsivo.</li>
</ul>
<h2>Notas</h2>
<p>
    Este projeto serviu como um exercício prático no uso do Grunt e seus plugins.
    Apesar de simples em funcionalidade, demonstra como task runners podem otimizar
    fluxos de trabalho front-end em ambientes de desenvolvimento e produção.
</p>
