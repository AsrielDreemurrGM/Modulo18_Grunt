<h1>Number Drawer - Grunt</h1>
<p>
    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A number drawer web application built with <strong>JavaScript</strong> and styled
    using <strong>LESS</strong>. The project uses the <strong>Grunt</strong> task runner
    to automate development and production tasks.
</p>
<p>
    🔗 Live Demo: <a href="https://sorteadorgrunteduardo-three.vercel.app" target="_blank">View on Vercel</a>
</p>
<h2>About</h2>
<p>
    The project was created to explore and practice task automation with Grunt.
    It includes configuration for multiple plugins to streamline both development
    and production workflows. Users can input a maximum number, and the app generates
    a random number within the defined range.
</p>
<h2>Technologies Used</h2>
<ul>
    <li>JavaScript</li>
    <li>LESS</li>
    <li>Grunt</li>
    <li>HTML5</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Compiling LESS into CSS;</li>
    <li>Minifying HTML, CSS, and JavaScript;</li>
    <li>Replacing file paths dynamically for builds;</li>
    <li>Cleaning temporary build folders;</li>
    <li>Watching files for changes and automating rebuilds;</li>
    <li>Concurrent task execution for faster workflows.</li>
</ul>
<h2>Commit Highlights</h2>
<ul>
    <li>Configured Grunt with development and production tasks;</li>

    <li>Implemented HTML and JavaScript minification for optimized builds;</li>
    <li>Configured Grunt Replace for dynamic file path handling;</li>
    <li>Improved form validation and number input behavior;</li>
    <li>Styled result messages and adjusted layout responsiveness.</li>
</ul>
<h2>Notes</h2>
<p>
    This project served as a practical exercise in using Grunt and its plugins.
    While simple in functionality, it demonstrates how task runners can optimize
    front-end workflows for both development and production environments.
</p>
